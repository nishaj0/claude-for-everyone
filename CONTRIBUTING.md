# Contributing

Everything lives in `README.md`. Add one table row to the right section (create a new `###` section under the right `##` category if none fits, and add it to the Contents list at the top). Things that run on their own and don't plug into an agent go under **Standalone**. Multi-tool recipes go in `PLAYBOOKS.md`.

Category names stay short and plain (`Video`, `Marketing`). The entry itself can be as descriptive as needed.

Columns: **Name** (linked to the repo or URL) · **Type** · **What it does** (one sentence) · **Use it when** (the situation, not a feature list). No install commands.

Rules:
- Free or freemium only. No paid-only tools or MCP servers.
- Only list things you've used or read the README of. No paid ads, no dead links.
- If an entry fits two categories, put it in the main one and add a cross-link in the other.
- Say so if it sends emails, runs code or spends money.
